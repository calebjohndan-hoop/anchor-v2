# Firmware

Arduino IDE 2.x, ESP32 Arduino core 3.x. Board: **ESP32S3 Dev Module**, Flash 16MB, PSRAM **OPI PSRAM**, USB CDC On Boot **Enabled**.

## v2: [v2/11_anchor_v2](v2/11_anchor_v2)

Noise cancelling in both ears plus the AI. It is v1 sketch 09 with each ear's state moved into an `Ear` object; the cancelling engine (`anchor_anc2.h`) and the AI files (`anchor_ai.h`, `anchor_ai_model.h`) are the v1 files, unchanged.

- Left ear: I2S port 0 on the v1 pins (5, 6, 7, 15), audio task on core 1
- Right ear: I2S port 1 (17, 18, 21, 16), audio task on core 0
- AI: listens to the left REF mic every 0.5 s and sets the mode for both ears
- Built-in AI by default; for the Edge Impulse model, install the `ANCHOR_inferencing` library and un-comment its `#include` line
- New keys: `1` left ear only, `2` right ear only, `3` both. The mode button recalibrates.

**Checked:** compiles and links for the ESP32-S3 (core 3.0.7) with the built-in AI and with the `ANCHOR_inferencing` Edge Impulse library (16 kHz, 1 s window, labels alarm, machine, other, voice).
**Not yet checked:** running on v2 hardware. Watch the per-ear `load` and `LOST DATA` numbers on first boot.

## v1: [v1/](v1/)

The v1 test sketches (`01_hello` to `10_music_player`), sketch 09 (mono cancelling + AI) and the Python tools for recording clips and training. Training audio and Edge Impulse exports are not included. Test sounds are generated by `tools/make_test_sounds.py`.

**v1 sketches run on the v2 left ear unchanged** (same pins, same mic slots, amps on by default), which is the first bring-up test.
