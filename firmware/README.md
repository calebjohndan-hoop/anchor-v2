# Firmware

Arduino IDE 2.x, ESP32 Arduino core 3.x, board: ESP32-S3 (16 MB flash, OPI PSRAM).

The v1 code is in [v1/](v1/): step-by-step test sketches (`01_hello` to `10_music_player`), the full mono ANC + classifier sketch (`09_anchor_full`), and Python tools for recording clips and training the classifier. Training audio and Edge Impulse exports are not included. v2 starts from `09_anchor_full` and adds the second ear.

Plan (see [../docs/DESIGN.md](../docs/DESIGN.md) section 10):
- Core 1: I2S0 full duplex + I2S1 slave input, 32 kHz, 8-sample blocks, two FxLMS channels, output limiter
- Start-up calibration of the speaker to ERR mic path; SAFE mode until it passes
- Core 0: four-class sound classifier on 1 second windows, mode changes after two matching windows
- Watchdog mutes the amps if the audio task stalls
Test sounds are generated by make_test_sounds.py.
